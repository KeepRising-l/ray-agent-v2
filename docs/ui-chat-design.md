# 对话界面整理

2026-11-01。按用户选择采用接近 ChatGPT 的对话布局：浅色默认，提供深色切换。目标是“把注意力留给问题和回答，让资料来源随手可查”。本轮属于 R09/R10 界面整理，未增加课程章节；助手协作实现，用户尚未阅读新增源码。

## 布局与取舍

左侧放新建对话、真实会话列表、知识库、任务、后台和账号；中央保留最大 760px 的回答阅读列，输入区留在底部。用户消息是浅灰气泡，助手使用开放正文。手机侧栏改为抽屉，来源窗口铺满宽度。

借鉴 ChatGPT 公开页面的阅读比例和输入关系，保留 RayAgent 自己的细线 R 标识、少量深青引用色与三模式说明。没有加入语音、图片等未实现入口，也没有增加组件库、字体下载或位图素材。

移除顶部平铺导航和重复大标题，取消逐条消息的分隔框；新会话模式、名称和资料范围放入创建窗口，运行细节按需打开。来源卡片只显示一次文件版本、页段信息，保留真实引用、失败、等待和权限边界提示。

浅色使用白色画布、浅灰侧栏和深色主按钮；深色使用 #212121 画布与 #181818 侧栏。变量集中在 `src/styles/app.css`。外观偏好存入 `ray-ui-theme`，退出仍清理私有浏览器状态，保留外观偏好。

## 代码入口

- `App.vue → AuthGate.vue → WorkspaceShell.vue`：认证后创建工作区，集中导航、主题和会话生命周期；退出销毁会话状态。
- `WorkspaceShell.vue → ChatWorkspace.vue → stores/chatSession.js`：布局与既有运行状态分开，继续使用原来的会话草稿、流归属和未确认请求恢复机制。
- `MessageContent.vue / MessageInline.vue / api/messageFormat.js`：有限的标题、列表、强调、引用和代码块排版；流式未闭合代码围栏仍可显示。使用 Vue 文本节点，不执行模型 HTML，也不声称完整支持 Markdown。
- 回答中的 K/W 来源仍按该条消息的 runId 查询。窗口内可核对引用原文，不把文件名按钮当作整份 PDF 下载。

Enter 发送，Shift+Enter 换行；输入法组合期间不发送。向上阅读时停止自动追随，提供回到最新消息按钮。创建失败保留名称及资料选择，保存失败保留表单，退出失败提示不会被固定工作区盖住。

## 动效与可达性

按钮有 80ms 按压和 160ms 状态反馈，侧栏有 200ms 位移，弹窗和消息有 160ms 淡入，空态有 180ms 进入；遵循 `prefers-reduced-motion`。原生 dialog 负责窗口焦点与 Escape，手机侧栏补齐焦点循环、关闭后焦点返回和背景 inert。窄屏图标保留可访问名称，阅读区支持键盘滚动。
