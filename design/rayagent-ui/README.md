# RayAgent 蓝灰工作台设计

这是参考旧版 RayAgent 后重新制作的可点击设计预览。用户体验后否定了上一版 V2 的外观，本次以自己的旧版为主要参考：恢复 keeprunning 小鬼标识、蓝灰侧栏、蓝色主动作、顶部模式入口和输入区内的模型选择。仍默认浅色，支持深色。

## 打开预览

前端依赖使用现有 `ray-agent-web/node_modules`，没有增加 npm 依赖。在工程根目录运行：

```powershell
node design/rayagent-ui/preview.cjs
```

打开 http://127.0.0.1:5175 。它与真实 V2 的 5173 页面分开，不会接触真实会话、密钥、数据库和模型。

当前交付是设计预览，尚未替换 `ray-agent-web` 的业务界面。对话、文档和来源均为自写固定内容；发送仅演示布局变化，不能用于判断模型回答、RAG 准确性或任务执行。新增对话在当前页面内存保存，刷新会回到固定初始内容；只有外观偏好保存在独立的本机存储键。

## 设计选择

目标：保留旧版熟悉的蓝灰工作台，让对话、模式和资料各在合适的位置。

桌面使用 276px 左侧栏，中央白色工作面板与最大 820px 的阅读列。新对话、近期历史及搜索在左，知识库和任务作为工作区入口，后台和个人账号放在底部。空态采用靠左的问候，只有两条建议问题；回答态使用开放正文、轻量用户气泡和紧邻回答的引用。

模式回到右上角菜单，保留中文名称和边界说明。选择其他模式会打开新对话配置，避免把旧会话的模式和资料范围改掉；知识库问答必须选择资料。模型位于输入框底部，发送操作独立、可见。手机保留模式文字、使用覆盖侧栏，来源窗口铺满屏幕。

主色来自旧版的蓝灰体系：浅色 `#f0f4f9`、白色与蓝色，深色 `#131314`、`#1e1f20` 与浅蓝。中文改用明确的微软雅黑/Segoe UI 本机字体栈。旧版问候中的蓝紫渐变仅保留在个人名字上，作为品牌连续性；正文、标签和按钮文字不使用渐变。品牌图标仅复用用户旧工程 `public/xiaogui.ico` 单个资产，其余代码在新目录重新编写。

删除重复的模式标签和大段首屏说明，去掉旧版的 Java 角标、背景开关、通知以及 V2 尚未实现的图谱、面试、人设入口；没有为了画面填满增加功能卡片。保留资料范围、引用文件/版本/段落和重要的模式边界。

按钮采用 120ms 反馈，侧栏 240ms、菜单 160ms、来源窗 220ms，并支持减少动态效果。保留键盘关闭、焦点返回、中文输入法组合保护、Shift+Enter 换行，以及短视口下的输入区。

## 文件

- `Preview.vue`：预览状态和界面，固定内容与真实服务隔离。
- `style.css`：浅深色变量、布局、状态与响应式。
- `main.js`：独立主题恢复及 Vue 挂载。
- `preview.cjs`：仅监听本机的独立 Vite 服务，复用已安装依赖。
- `assets/brand.ico`：用户旧版的品牌资产。

## 实际检查

主代理使用已安装 Playwright/Chrome 运行 `node tools/verify_ui_design.cjs`，连续三次通过。覆盖搜索、会话读回、建议问题、输入法、创建模式与资料范围、逐条来源、焦点返回、手机菜单、短视口/200%输入区，以及主题刷新与保存失败回退；同时断言没有 `/api/` 请求。没有运行生产构建、全量测试或真实业务验证。

独立结构检查通过；一轮独立改版视觉评审为8/10，反馈的重复模式标签和空泛欢迎文案已删除。独立UX在桌面和手机模拟视口走通新建资料问答、发送、引用及返回，未确认关键障碍。预览生成了录屏和动效探测，但未将其当作正常速度观感完整验收或手机真机验证。

过程截图和报告位于受忽略的 `logs/ui-rayagent/`：`legacy-light/dark.png` 是旧版实际源码运行截图；`checks/` 是交互检查状态；`evidence-final/` 是桌面截图、2倍像素图与录屏；`structure-review.md`、`visual-review/review.md` 和 `ux-review/report.md` 记录独立检查。截图工具仅提示名字使用渐变，保留理由如上；首页仅等待加载的取证组没有操作，未检测到动作动画不需要补无目的动画。

实现、用户阅读和验证状态仍统一记录在原规划目录；本设计未提交或推送，也不计为用户已掌握源码。
