# R11 故障验证矩阵

下表区分真实基础设施与受控故障。HTTP503、延迟、错误JSON及进程中断均由隔离脚本注入，不冒称外部供应商真实事故。脚本只使用自己创建的schema、存储与进程。

| 场景 | 可观察结果 | 当前证据 |
| --- | --- | --- |
| 单槽与两格队列并发 | FIFO、第三个排队后后续429；429没有落run | R08夹具与R11隔离压测通过 |
| 同请求/同会话并发 | 原编号409并可查询，不重复执行；同会话互斥 | R08模拟与真实转发回归通过 |
| 排队取消/超时 | 不调用模型，释放预留槽；不扣实际执行预算 | R08受控验证通过 |
| RUNNING/QUEUED时进程异常退出 | 重启标INTERRUPTED，不整轮重放 | 隔离真实PG、受控kill通过 |
| 文档Embedding先503 | 有限退避，独立尝试记录，片段与向量不重复发布 | 模拟与真实Embedding转发通过 |
| 文档处理中进程退出 | 标中断，明确重试后完整发布 | 隔离PG、模拟及真实Embedding通过 |
| 等待用户时重启 | 不占执行槽，原run/question接续，结果唯一 | R08模拟与真实模型回归通过 |
| 关键词查询异常 | 同向量/同范围回退基线，不重复Embedding | Mockito受控故障单测通过 |
| 重排编造/重复/缺失ID或坏JSON | 拒绝该排序，沿用原候选；不能扩证据 | 单测与模拟HTTP业务回退通过 |
| 重排预算不足 | 留出判断和回答次数，不多发重排调用 | 单测通过 |
| 接续前实验策略变化 | 旧快照保留，不能悄悄换策略消费原问题 | 运行快照与重启开关验收；版本不兼容返回409 |
| 资料越owner/库/维度 | 两路共用过滤，距离计算前排除异空间 | 真实PG测试覆盖 |
| 认证/CSRF/后台幂等 | 匿名拒绝、缺CSRF拒绝、重复补偿只返回原记录 | R10完整回归，R11沿用 |
| 新卷启动/数据库停止/恢复 | 本地健康503，恢复后就绪；账号资料重启保留 | 以clean-start.json及质量报告实际结果为准 |

恢复动作和边界见[恢复手册](../../docs/operations/recovery-playbook.md)。公开部署、真供应商限流故障、分布式多实例容量与任意步骤恢复不在本次验证范围。
